ITIDEAS 3D Viewer is a mobile-first inspection app for iPhone used to preview manufacturing models before 3D printing or CNC. Core workflow: Load → Fit/ISO → verify X/Y/Z in mm → inspect Solid/Edges/Wireframe and standard views → measure critical two-point distances → capture a reference image. Primary file targets: STL, 3MF, STEP/STP. Keep the 3D viewport dominant, controls thumb-friendly, and engineering measurements precise.
