Precision inspection instrument. The interface should feel like a premium metrology tool: deep graphite surfaces, hairline technical dividers, tabular numerals, restrained cyan signal accents, and minimal decoration. Dark-only. Tight pacing for one-handed iPhone use. Surfaces are layered but nearly flat; shadows are subtle, radii compact, and controls read as calibrated instruments rather than consumer-app pills. Typography uses IBM Plex Sans for UI and JetBrains Mono for measurements, coordinates, dimensions, and file metadata. Cyan is reserved for active tools, selection points, dimension lines, and primary actions; warning/error states remain semantically distinct. The 3D viewport is always visually dominant and tool chrome must never obscure the model.
