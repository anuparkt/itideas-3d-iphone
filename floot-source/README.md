# ITIDEAS 3D Viewer — Floot source

Source snapshot for Floot project `615f2595-f79f-4e12-9d60-5d1d1c18b7f6`.

Floot preview: https://floot.com/mcp-preview/615f2595-f79f-4e12-9d60-5d1d1c18b7f6

Core workflow: Load → Fit/ISO → verify X/Y/Z in mm → Solid/Edges/Wireframe → standard views → two-point measurement → capture.

Current model loading: STL and 3MF. STEP/STP is listed in the UI but its parser is not implemented in this build.

The existing root `index.html` is intentionally kept unchanged. This folder contains the Floot React/Three.js source snapshot so it can be versioned in GitHub.
